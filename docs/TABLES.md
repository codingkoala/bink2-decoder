# Bink 2 constant tables

Numeric constants needed to decode Bink 2 video. See [SPEC.md](SPEC.md) for how each is used and for the provenance note. VLC codes are written as the sequence of bits in the order they come out of the LSB-first bit reader (leftmost = first bit read). All codes in a table are prefix-free.

## Shared

**Z-order of 8x8 blocks in a 32x32 macroblock** (`ZORDER[k]` = `row*4 + col` of the k-th block):
```
 0  1  4  5  2  3  6  7  8  9 12 13 10 11 14 15
```

## AC run symbols (both variants)

| symbol | meaning |
|---|---|
| 0..10 | advance the coefficient position by this many |
| 11 | escape: advance by the next 6-bit value |
| 12 | end of block (float: advance by 62; integer: advance by 64) |
| 13 | advance by 0; the coefficient here and the 6 after it are coded back to back, with no run code between them |
